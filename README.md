# Iniciante em Programação: JavaScript

Exercícios que fiz enquanto aprendia JavaScript, do mais simples ao mais completo. Este repositório é o registro da minha evolução nos primeiros passos com a linguagem.

## 📁 Estrutura

### `desafios-alura/`
Desafios do curso de lógica de programação da Alura.

| Arquivo | O que pratica |
|---|---|
| `00-meu-primeiro-codigo.js` | Meu primeiro código: `prompt`, `alert` e um `if/else` simples |
| `desafio-01.js` | Declaração de variáveis e mensagens com `alert` |
| `desafio-02.js` | Entrada de dados e condicional (verifica se a pessoa pode tirar habilitação) |
| `desafio-03.js` | Primeira versão do **jogo do número secreto** |
| `desafio-04.js` | Jogo do número secreto com validação de entrada (número entre 1 e 100) e `else if` |

## ▶️ Como executar

Os códigos usam `prompt()` e `alert()`, que funcionam no **navegador**:

1. Abra qualquer página no navegador e aperte `F12` para abrir o **Console**
2. Copie o conteúdo do arquivo, cole no console e aperte `Enter`

## 🧠 O que aprendi

- Variáveis (`let`)
- Template strings (`` `Olá ${nome}` ``)
- Condicionais (`if`, `else if`, `else`) e operadores lógicos (`&&`, `||`)
